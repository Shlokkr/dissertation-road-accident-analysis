# dissertation-road-accident-# 🚗 Weather Impact Analysis on Road Traffic Accidents

## 🚀 Key Outcome
- Analysed 100K+ records from UK transport data
- Built ML models to classify accident severity
- Identified weather and time as key risk factors

## 📌 Overview

This project analyses UK road traffic accident data to understand how weather conditions and temporal factors influence accident severity. The goal was to identify key risk patterns and support data-driven road safety decisions.

## 🎯 Objectives

* Analyse accident trends across different weather conditions
* Identify factors affecting accident severity
* Build and evaluate machine learning models
* Visualise insights using Power BI dashboards

## 🧠 Technologies Used

* Python (Pandas, NumPy, Scikit-learn)
* Data Cleaning & Preprocessing
* Feature Engineering
* Machine Learning Models:

  * Random Forest
  * Logistic Regression
  * Decision Tree
* Power BI (Dashboard Development)

## 📊 Dataset

* UK Department for Transport datasets:

  * Accidents
  * Vehicles
  * Casualties

## ⚙️ Process

1. Data cleaning and preprocessing
2. Dataset merging and feature engineering
3. Exploratory Data Analysis (EDA)
4. Model training and evaluation
5. Dashboard development in Power BI

## 📈 Key Insights

* Most accidents occur during **fine weather conditions**
* However, **poor weather conditions lead to higher severity**
* Time-of-day plays a significant role in accident frequency
* Traffic volume strongly influences accident occurrence

## 📊 Dashboard

The Power BI dashboard includes:

* Accident trends over time
* Weather-based accident analysis
* Severity distribution
* Time-of-day insights

## 🚀 Results

* Built predictive models for accident severity classification
* Identified high-risk conditions for road safety
* Delivered an interactive dashboard for decision-making
